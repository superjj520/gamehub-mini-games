# 3D 资产管线约定

状态：产品基线与视觉方向已确认；候选资产导入门禁已生效，最终美术资产仍需逐项签收。

## 坐标与单位

- 引擎：Godot 4.x。
- 世界单位：1 个单位等于 1 米。
- 角色默认高度：1.8 米；站立碰撞体原点位于脚底中心。
- 前进方向：角色和载具的局部 `-Z`；垂直方向为 `+Y`。
- 场景地面高度：`Y=0`；可行走角色中心通常为 `Y=0.9`。

## 原点规则

- 角色：脚底中心。
- 载具：车体几何中心，车轮接触面位于父节点下方约 0.5 米。
- 建筑和模块化墙体：底面中心或可拼接角点。
- 道具：放置底面中心；手持道具另设握持挂点，不在运行时用魔法偏移修正。
- 标牌和 UI 牌：牌面中心，朝向由父节点或广告牌材质控制。

## 命名与目录

运行时导出资产使用以下目录，不与 DCC 源文件混放：

```text
art-source/<类别>/<资产名>/       # .blend、设计稿、原始贴图
gta-reference-runtime/assets/<类别>/<资产名>/  # 进入运行时的 .glb、贴图、材质
```

类别固定为 `characters`、`vehicles`、`environment`、`props`、`ui`、`audio`。
资产名使用小写英文和短横线；面向玩家的中文名称只能出现在内容包或 UI 文案中。

## 导出与导入

- 首选格式：glTF/GLB。
- 导出前应用缩放、旋转和位置变换；保留骨骼、蒙皮、UV、顶点色和必要的切线数据。
- 不在场景脚本中写每个模型的独立缩放或旋转补丁。
- 原始工程文件、导出文件和发布包必须分离保存。
- 最终导入前必须检查尺寸探针、朝向、原点、碰撞体、命名、面数和贴图分辨率。
- 可用 `npm run verify:asset-budgets` 对已登记候选执行统一技术预算检查；该命令检查三角面、实际使用材质槽、骨骼数、贴图尺寸、候选登记路径和运行时哈希。命令失败时只能返回资产制作阶段，不能进入最终资产槽位。
- 可用 `npm run verify:asset-conventions` 对登记候选执行统一导入契约检查；机器清单位于 `docs/3d-asset-pipeline-contract.json`，检查米制包围盒、脚底/车体原点、根节点单位变换、场景数量和可导入网格，并把结果写入 `reference-evidence/candidate-runtime/asset-convention-verification.json`。该命令通过只代表技术接入前置条件满足，不代表视觉、权利、目标设备或发布验收通过。
- 当前 Quaternius 城市候选的导入探针由 `gta-reference-runtime/tests/asset_import_validation_test.gd` 执行；主角和办公室 NPC 的独立服装候选分别由 `gta-reference-runtime/tests/inspect_outfitted_asset.gd`、`gta-reference-runtime/tests/inspect_npc_outfitted_asset.gd` 执行。它们只证明 GLB 可导入、骨架和候选对象结构符合约定，不等于最终资产通过。

## 首发性能预算草案

在用户确认目标平台前，只把它作为上限草案，不作为发布承诺：

| 类别 | 单体三角面上限 | 贴图上限 | 备注 |
|---|---:|---:|---|
| 主角 | 35,000 | 2048 | 需要完整行走、蹲伏和交互动画 |
| NPC | 18,000 | 1024 | 可按距离切换低模 |
| 载具 | 25,000 | 2048 | 车体、货箱和碰撞分离 |
| 建筑模块 | 12,000 | 1024 | 优先模块化复用 |
| 小型道具 | 4,000 | 512 | 批量实例化 |

目标平台确认后，必须用真实设备重新制定帧率、内存、加载和纹理预算。

候选远景建筑可以暂时使用更高于“最终建筑模块”预算的原始网格，但必须留在候选目录并标记 `release_allowed=false`；进入首发资产槽位前要完成减面、LOD、材质合批和目标设备复测。

## 接入检查表

新资产进入运行时前必须记录：

1. 来源、许可证和发布权限。
2. 单位、朝向和原点检查结果。
3. 碰撞体和交互挂点检查结果。
4. 面数、材质数量和贴图尺寸。
5. 至少一张运行时截图和一个真实交互回放。
6. 是否通过目标平台性能测试。

预算检查证据写入 `reference-evidence/candidate-runtime/asset-budget-verification.json`。技术预算通过只表示几何与导入规模合格，不代表视觉、权利、Windows 目标设备或发布验收通过。

参考视频帧只作为内部构图和行为证据，不得直接导入为商业发布资产。
