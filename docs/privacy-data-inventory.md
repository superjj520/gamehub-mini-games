# 数据收集与隐私边界清单

状态：开发基准版；不是最终隐私政策。平台、账号体系和商业化方案确认后必须由负责人复核并改写为面向用户的正式政策。

## 当前运行时实际行为

| 数据类别 | 当前是否收集 | 当前用途 | 存储位置 | 是否上传 |
|---|---|---|---|---|
| 任务进度 | 是 | 本地恢复办公室/城市任务 | Godot `user://` 存档 | 否 |
| 输入回放 | 是 | 内部测试和问题复现 | Godot `user://` 回放文件 | 否 |
| 事件时间轴 | 是 | 内部验收和调试 | Godot `user://` 追踪文件 | 否 |
| 设备标识 | 否 | 当前没有账号和分析服务 | 无 | 否 |
| 联系方式 | 否 | 当前没有客服表单或账号系统 | 无 | 否 |
| 支付信息 | 否 | 当前没有商业化 | 无 | 否 |
| 参考视频和抽帧 | 否 | 只在研发工作区内部验收 | 工作区外部参考目录 | 否 |

## 当前禁止的默认行为

- 不接入广告、第三方分析、崩溃上传、社交登录或远程存档。
- 不把本地存档、输入回放或事件时间轴自动上传。
- 不把参考视频、抽帧、来源链接或内部验收数据打进发布包。

## 上架前必须确认

1. 首发平台的隐私披露字段和数据安全表。
2. 是否引入账号、云存档、分析、广告或支付 SDK。
3. 崩溃报告是否收集设备型号、系统版本、日志或 IP 地址。
4. 未成年人、跨区传输、删除请求和客服入口要求。
5. 隐私政策 URL、用户协议、客服邮箱和数据删除流程负责人。

当前结论：开发基准版无网络数据收集，但不能据此直接生成任何平台的最终隐私声明。

## 机器校验入口

`npm run verify:privacy-boundary` 会校验本清单的核心数据类别和声明，并扫描当前运行时脚本、场景与配置，阻断未登记的网络、账号、广告、分析和支付接入。该检查只证明开发基线边界，不替代平台隐私政策、数据安全表或法务审阅。
