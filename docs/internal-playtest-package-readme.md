# 新时代觉醒者：内部桌面源码试玩包

这是平台无关的 Godot 4.7 源码试玩包，不是 `.app`、`.exe` 或手机安装包。

## 启动

第一次启动前，在本目录执行一次资源导入：

```bash
godot --path . --import
```

导入完成后启动：

```bash
godot --path .
```

如果使用 Godot 编辑器打开 `project.godot`，编辑器会自动完成同样的资源导入。

启动器中可以选择办公室任务或城市任务。当前灰盒输入为：WASD 移动、鼠标/方向键控制镜头、C 蹲伏、E 交互、R 重试、L 读取存档、V 上下车、F 触发冲突、Space 闪避、Esc 暂停。冲突中按 F 可近战反击，按 Space 可在短窗口内闪避伤害，也可以拉开距离逃脱。

## 边界

- 当前是内部研发候选，不代表可上架。
- 角色、环境、动画、音频和 UI 仍为灰盒或程序化候选；载具已接入第一版独立 GLB 候选，但仍未完成最终视觉签收。
- 两个参考视频没有打入本包，仅作为内部验收证据使用。
- 正式平台已确认是 Steam Windows；Windows 10/11 真机、商店材料和上架门禁尚未完成。

## 来源

当前包绑定运行时源指纹：`__SOURCE_FINGERPRINT__`，正式运行时源文件 __SOURCE_FILE_COUNT__ 个；Godot 自动生成的 `.import` 与 `.uid` 元数据不计入指纹。本版包含候选资产预览入口、载具车轮滚动反馈及对应导入契约测试，但仍是内部候选。最终角色、环境、动画、音频、视觉签收、Windows 真机和 Steam 门禁仍未完成。
