# 大转盘 V1 设计规格

**状态：** 已确认，进入实现前的唯一功能与交互依据。  
**目标：** 将大转盘从技术演示升级为一款可创建、试玩、发布、分享和游玩的独立小游戏。

## 产品边界

大转盘服务“朋友聚会随机选择”和“小型活动抽奖”两类场景。两类场景通过预设解决，不拆成两种游戏。

创作者可以选择预设、编辑内容、调整外观、进行实时试玩、保存草稿和发布。玩家只能通过分享链接游玩、再玩和分享；玩家不能查看配置、编辑、复制或改编游戏。

不包含真实下注、余额、支付、奖品履约或公开游戏库。

## 页面与流程

```text
创作者站 creator.html
  → 选择“幸运转盘”
  → create-v2.html?game=wheel
  → 内容 / 样式 / 高级几何
  → 实时试玩
  → 保存草稿 / 发布
  → 获得玩家站分享链接

玩家站 play-v2.html?game=wheel&config=<分享标识>
  → 理解本局标题和奖项
  → 开始抽奖
  → 结果
  → 再玩 / 分享
```

## 创作者工作台

采用左侧控制台、右侧实时转盘舞台的双栏布局。移动端先显示舞台和主要操作，再显示可折叠控制台。

### 内容

- 官方预设：聚会随机选择、活动抽奖、真心话大冒险。
- 奖项列表支持新增、删除、重命名、选择图标和调整权重。
- 奖项至少两个，名称不能重复，权重大于零。
- 扇区数量始终由奖项数量决定，不能独立编辑。

### 样式

- 主题：霓虹极光、金奢夜场、糖果聚会、节日喜庆。
- 可设置扇区文字显示、文字方向和文字距离。
- 所有主题只影响呈现，不改变中奖规则。

### 高级几何

- 外半径、扇区间距、中空中心、内孔半径、外圆角、内圆角和起始角度。
- 高级几何默认折叠，普通创作者不必理解这些参数。
- 参数被限制在安全范围，不能使转盘不可读或不可点击。

### 操作

- 修改任意配置立即刷新右侧预览。
- “试玩”使用当前配置、但不写入游玩数据。
- “保存草稿”持久化当前版本，仅创作者可继续编辑。
- “发布”冻结一个可游玩的配置版本，生成分享标识与玩家站链接。

## 玩家体验

- 玩家页只加载发布版本，不能读取创作器控制项。
- 转盘先由规则引擎确定结果，再播放对应角度的旋转动画。
- 指针停靠后，中奖扇区高亮，显示结果弹层。
- 结果弹层只包含“再玩一次”和“分享游戏”。
- 同一分享链接可重复游玩；不展示创作者的草稿或历史版本。

## 数据与模块边界

`games/wheel/config.js` 负责默认值、预设、校验与迁移；`engine.js` 只负责按权重确定结果；`player.js` 只负责转盘渲染和动画；`editor.js` 只负责创作者控制项。

配置 payload：

```js
{
  title: '今晚谁买单？',
  prizes: [{ id, name, icon, weight, color }],
  theme: 'neon',
  labels: { visible: true, direction: 'horizontal', offset: 0.62 },
  geometry: { radius: 205, gap: 3, hollow: true, innerRadius: 80, outerRound: 18, innerRound: 12, startAngle: -90 }
}
```

草稿与发布版本使用平台 `GameConfig` 契约持久化。分享引用发布配置的标识，URL 不承载奖项和概率。当前内存型 config/share 服务将替换为浏览器持久化适配层，并保留未来接入 Supabase 的接口边界。

## 验收标准

- 创作者可从预设开始，并在三分钟内完成一局可分享的大转盘。
- 配置改变会同步更新预览，不刷新页面。
- 发布后生成可在另一浏览器会话中读取的分享配置。
- 玩家从分享链接进入后只能抽奖、再玩和分享。
- 中奖扇区与规则引擎结果一致，权重校验可测试。
- 空奖项、重复名称、非法几何参数会显示明确错误。
- 新实现不依赖旧版 `builder-v2.html` 或其他游戏目录。
