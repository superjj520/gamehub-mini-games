# 大转盘 V1 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付可配置、可试玩、可发布分享的大转盘，并让玩家只能游玩、再玩和分享。

**Architecture:** `games/wheel` 负责纯配置、概率规则、SVG 转盘和创作器；页面只编排模块并通过浏览器持久化适配层保存发布版本。发布链接只携带配置标识，玩家页加载已发布快照，结果先由引擎决定、再播放动画。

**Tech Stack:** 原生 HTML/CSS/JavaScript、SVG、Node 内置测试、Playwright、浏览器 `localStorage`。

## 全局约束

- 所有文案、注释、提交信息使用中文。
- 不引入框架或新的运行时依赖。
- 玩家端不包含编辑、复制或改编入口。
- 转盘扇区数由奖项数派生，概率与视觉参数分离。
- 旧版 `builder-v2.html` 不作为新大转盘入口。

```js
function updatePrize(config, index, patch) {
  var prizes = config.prizes.map((prize, itemIndex) => itemIndex === index ? Object.assign({}, prize, patch) : prize);
  return normalizeConfig(Object.assign({}, config, { prizes }));
}
```
