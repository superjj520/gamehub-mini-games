# 参考还原型第三人称任务游戏 GDD

版本：0.2
状态：产品基线已确认；最终资产与发布门禁未完成

产品定稿入口见：[产品基线与定稿入口](/Users/superjj/gamehub-mini-games/docs/product-baseline.md)。

## 1. 玩家承诺

玩家将在一个具有现实生活质感的三维场景中，以第三人称视角完成明确任务。玩家需要观察环境、控制角色、利用场景、规避或处理 NPC 反应，并在成功、失败和重试之间形成连续的任务体验。

本项目借鉴 GTA 类型的第三人称城市任务运行方式，但不使用 GTA 或其他第三方游戏的名称、角色、地图、声音、模型、代码、商标或可识别资产。

## 2. 产品支柱

1. **参考可验证**：视频中可观察的行为、镜头、状态和反馈都必须有实现或明确的待确认记录。
2. **任务驱动**：玩家始终知道当前目标、失败风险和下一步行动。
3. **真实状态**：NPC警觉、交互、任务完成和失败都由真实状态机驱动，不用假按钮或静态演示替代。
4. **可扩展运行时**：办公室潜行和城市任务共享角色、镜头、NPC、任务、交互和存档能力。

## 3. 目标玩家

### 暂定目标玩家

- 喜欢短时、强反馈、现实题材任务游戏的玩家。
- 喜欢潜行、观察路线和处理突发状态的玩家。
- 喜欢第三人称城市探索和轻度任务链的玩家。

### 暂定单局长度

- 首发垂直切片：5 至 10 分钟。
- 后续城市任务：10 至 20 分钟。

以上时长是制作假设，需在真实试玩后修订。

## 4. 首发产品范围

### 首发垂直切片：准点下班

玩家需要在规定时间到达出口，并避免被上司或同事发现。

首发必须具备：

- 第三人称移动。
- 正常移动和蹲伏。
- 办公桌、隔断、墙角和走廊形成的遮挡关系。
- NPC视野、警觉值、怀疑和发现状态。
- 时间从 `17:59` 推进到目标时间。
- 出口或电梯交互。
- 成功、失败和重试。
- HUD目标、时间、警觉和结果提示。
- 本地存档或至少可恢复的任务状态。

### 后续内容包：中国街区任务

在运行时通过首发验收后再加入：

- 商店和街道。
- 人群和简单冲突。
- 免费鸡蛋任务链。
- 物品携带。
- 三轮车上下车与驾驶。
- 登记或扫码点交互。
- 金钱、星级和连续任务。

## 5. 核心循环

```text
接受任务
→ 观察场景
→ 选择路线
→ 移动、蹲伏或使用掩体
→ 处理 NPC 警觉
→ 到达交互目标
→ 检查完成条件
→ 成功、失败或重试
```

## 6. 系统规则

### 角色

- 角色移动速度、蹲伏速度和碰撞半径必须是配置项。
- 首发 Windows 版本统一提供键鼠和手柄映射；触屏输入不属于当前首发范围，未来若扩展移动端必须单独建立触屏布局与目标设备门禁。
- 角色状态必须被任务和回放系统读取。

### NPC感知

- 感知由距离、视野角、遮挡、玩家姿态和警觉累积共同决定。
- 警觉状态：平静、怀疑、发现、丢失目标。
- 每个状态变化必须产生可测试事件。

### 任务

- 任务状态：未开始、进行中、成功、失败。
- 任务目标不能由 HUD 自己修改。
- 失败必须说明原因，并提供可重复的重试入口。

### 交互

- 交互必须有距离、条件、输入和结果。
- 没有真实状态变化的交互控件不得出现在正式版本。

## 7. UI范围

首发 HUD 只包含：

- 当前任务。
- 当前时间。
- 警觉状态。
- 交互提示。
- 成功或失败反馈。

城市内容包再增加小地图、金钱、生命、星级和载具提示。

## 8. 非目标范围

首发不包含：

- 联机模式。
- 用户创作地图。
- 多层办公楼。
- 复杂对话树。
- 账号系统。
- 真实经济系统。
- 复制任何现有商业游戏资产。

## 9. 产品验收标准

### 功能

- 玩家首次进入后 30 秒内可以开始任务。
- 玩家能理解目标、风险和交互方式。
- 任务可以正常完成，也可以失败并重试。
- 相同输入和相同随机种子可以重现同一结果。

### 参考还原

- 关键镜头、角色位置和状态变化有时间轴记录。
- 关键 HUD 状态与参考视频逐项比对。
- NPC发现时机、任务目标切换和失败反馈必须通过验收。

### 工程质量

- 有自动化规则测试。
- 有真实场景烟雾测试。
- 有目标设备性能记录。
- 发布构建可重现。

## 10. 当前决策、假设与开放问题

### 已决定

- 采用三维第三人称任务游戏方向。
- 采用原创内容，不复制第三方游戏资产。
- 以逐项证据和测试作为完成标准。
- 先建立运行时，再扩展内容包。

### 当前假设

- Godot 4.x 作为第一轮运行时底座。
- 先用办公室潜行验证核心状态机。
- 城市任务作为后续内容包开发。

### 已确认但仍未完成验收

- 正式首发平台为 Steam Windows，首发设备为 Windows 10/11、1080p、键鼠与手柄；目标设备实测仍未完成。
- 单人开发，办公室垂直切片估算投入为 20–35 人周；这不是最终排期或质量豁免。
- “中国街区任务”保留为办公室首发之后的扩展内容包，不自动进入首发发布范围。

### 仍等待负责人定稿

- 品牌与 Logo 的最终视觉规范。
- 客服入口、隐私政策 URL、年龄分级、运营主体和公开测试日期。
- 参考视频若要进入游戏、商店页面或宣传片，需单独确认发布用途和生成工具/输入素材的许可边界。
