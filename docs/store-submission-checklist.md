## 图标、截图和视频

- 图标：待品牌和平台尺寸确认。
- 商店截图：禁止使用内部参考帧；必须来自授权或原创最终运行画面。
- 宣传视频：禁止使用两个参考视频、抽帧或其音频；必须重新录制原创运行时。
- 文案：不得使用 GTA、参考视频原产品名称、第三方角色名或受保护商标作为产品宣传内容。
- 年龄分级：已有内部问卷草案；需要根据最终冲突、伤害表现、语言和商业化内容重新申报，见 `docs/age-rating-questionnaire-zh-CN.md`。

## 提交前硬门禁

1. 目标平台和发行地区已由用户确认。
2. 正式导出包与经过测试的构建完全一致。
3. 参考验收清单中的阻断条目有截图、回放和目标设备证据。
4. 最终资产、字体、图标、音频和第三方库均有发布权限。
5. 隐私、客服、年龄分级、商店文案和回滚方案齐全。

当前结论：只允许内部开发验证，禁止提交任何商店。

## 证据索引

所有提交前证据统一由 `docs/store-submission-evidence-index.json` 汇总，并绑定当前运行时源指纹、内部包哈希和门禁状态。生成并验证索引：

```bash
npm run submission:evidence-index
```

索引是内部交接材料，不是商店提交凭证；只要视觉、最终资产、权利、Windows 真机或负责人字段仍未通过，索引必须保持 `internal_no_go`。
