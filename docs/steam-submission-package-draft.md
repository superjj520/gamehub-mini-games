## 2. 页面文案草案

页面中文文案的唯一审阅源见：[Steam 中文商店文案包](steam-store-copy-zh-CN.md)。本节保留提交包摘要，若两处文字冲突，以文案包和最终负责人签收为准；在 `internal_draft / do_not_submit` 状态解除前，不得复制到真实商店页面。

### 短描述

在下班铃响前穿过办公室，读懂 NPC 的警觉，完成一场关于时间、路线和选择的第三人称任务。

### 长描述

《新时代觉醒者》是一款原创第三人称任务游戏。你需要在有限时间内观察办公室路线、避开 NPC 的感知、完成交互目标，并在失败后重新选择路径。

本作的核心体验建立在可重复的任务状态机上：移动、蹲伏、镜头观察、NPC 警觉、交互、失败、重试和检查点恢复彼此关联。后续城市街区内容将复用同一套角色、镜头、任务、交互、载具和存档运行时。

### 功能描述候选

- 第三人称移动、蹲伏和环绕镜头。
- 基于距离、视野、遮挡和姿态的 NPC 感知。
- 可失败、可重试、可从检查点恢复的任务流程。
- 办公室潜行、路线选择和物品交互。
- 本地存档、输入回放和确定性行为验证。
- 城市任务、三轮载具和背景交通作为后续扩展内容。

### 不能放入正式页面的表述

- “100% 还原”、 “完全复制”或暗示来自第三方游戏的文案。
- 尚未签收的最终画质、完整音频、联机、账号、云存档、支付或跨平台能力。
- 参考视频中的角色、场景、标识、字幕、音频或抽帧图片。
- 未完成 Windows 真机验证前的帧率、兼容性和设备承诺。

系统要求、内容提示、语言支持、截图镜头顺序和预告片交接规则见上述文案包；这些条目目前均属于待实测或待签收字段。

统一登记入口：[发布负责人输入清单](release-owner-inputs.json)。在这些字段确认前，本草案只能用于内部审阅，不能创建真实商店提交或上传配置。

## 6. 提交前顺序

1. 完成最终资产和权利登记。
2. 在 Windows 10/11 目标设备完成输入、存档、性能和视觉 QA。
3. 重新采集当前源 21 段正式视觉与 18 项扩展视觉，并完成人工签收。
4. 录制不含参考视频素材的商店截图和宣传视频。
5. 补齐运营主体、客服、隐私、分级、Steam 应用编号和测试日期。
6. 生成绑定同一源指纹的正式候选构建，运行 `npm run release:preflight`。
7. 只有门禁结论为 `release_go` 后，才允许进入 Steamworks 提交流程。
