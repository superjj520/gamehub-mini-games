# 《新时代觉醒者》原创视觉规范

版本：`0.1.0-dev`  
状态：`candidate_direction`；用于 P0 资产生产，不等同于最终视觉签收。

## 1. 视觉目标

以两个参考视频中已经验证的肩后第三人称可读性为基准，制作原创的城市生活与办公室潜行视觉。目标不是复制参考视频中的角色、地图、招牌或品牌，而是保持以下体验关系：角色在遮挡空间中清楚可见，任务状态在第一眼可读，NPC 的警觉方向可以通过姿态和标记理解，城市入口、店铺和载具具备连续地标。

## 2. 四条风格支柱

1. **原创生活化写实**：服装、办公用品、店铺和街道来自新时代的普通城市生活，不使用 GTA 或参考视频中的名称、商标、模型和纹理。
2. **中等细节、远近一致**：主角近景能读出发型、服装、背包和手部；远景只保留轮廓、颜色和状态，不用无意义的高面数堆细节。
3. **暖冷分区**：办公室采用米灰墙面、木色工位和暖色顶灯；城市采用冷灰道路、饱和但克制的店铺色块和可识别的交通色。
4. **行为优先可读**：蹲伏、交互、搜索、警觉、失败和载具损伤必须优先于装饰细节；任何装饰不能遮挡任务目标、NPC 视线标记或 HUD。

## 3. 形体和材质规则

- 主角：成年比例，肩后镜头中背包不能遮住脚底和蹲伏轮廓；服装使用 2 至 4 个主色块，避免纯黑一团。
- NPC：上司与巡查员用服装、体型和警觉动作区分，不用头顶文字替代轮廓设计。
- 办公室：工位、隔断、走廊和电梯厅必须保持现有碰撞与遮挡关系；材质优先粗糙度差异和边缘高光，不复制参考帧纹理。
- 城市：店铺门头、道路边缘、货架通道和后场装卸点各有一个明确识别特征；招牌文字必须原创并通过商标审查。
- 三轮车：蓝色车体是玩法识别色，但车体结构、灯、座椅、货架和损伤状态必须独立设计。

## 4. 可读性验收

每个资产必须在 1280×720、肩后镜头和目标交互距离完成以下检查：

- 1 秒内识别玩家、NPC、交互物和载具的类别。
- 角色移动、蹲伏、搜索、受击和失败状态可通过姿态区分。
- 背包、服装和手持物不穿过隔断、桌面、车体或镜头。
- HUD 与场景主色对比足够，任务、警觉、生命和载具耐久不互相遮挡。
- 远景低模或材质简化不改变任务目标和危险方向的判断。

## 5. 资产生产与发布规则

- 首选 glTF/GLB；1 单位等于 1 米，角色脚底为原点，局部前进方向为 `-Z`。
- 资产源文件、运行时导出文件、内部证据和发布包必须分离。
- 参考视频和抽帧只进入内部验收链，不作为纹理、材质、宣传图或音频。
- 资产在权利、运行时接入、行为回放、固定镜头、目标设备和人工审阅全部通过前，保持 `unverified`，不得进入 `release_allowed=true`。
