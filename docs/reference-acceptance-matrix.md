## 5. 验收规则

每一行只有在以下证据都存在时才允许标记为通过：

1. 参考时间段有对应截图或原始帧号。
2. 运行时事件时间轴中出现对应事件。
3. 真实场景可以通过输入回放重现该事件。
4. 画面截图包含角色、镜头、HUD和关键对象。
5. 失败、重试和边界条件都有独立记录。

机器门禁还会逐行核对运行时截图的 SHA-256、视觉对照报告是否指向当前截图、事件轨迹是否存在，以及本行声明的每个运行时事件是否真实出现在轨迹中。仅修改 `acceptance-status.json` 的状态字段不能绕过证据链。

## 6. 当前不可宣称完成的项目

- 最终角色模型和动画。
- 参考视频中的真实办公室布局。
- 真实商店货架和人群行为。
- 最终载具手感和街道交通。
- 音效、对白和反馈节拍。
- 原始视频分辨率下的像素级视觉一致性。

没有对应证据的条目必须保持“未实现”或“部分实现”，不能用灰盒截图替代最终还原结论。
