# 《新时代觉醒者》玩法状态归属与更新顺序

版本源：`cdb48da59d56c7dfa13bd9676c8c9f49b74c040e4946a1a72fdd7de9479a4420 / 232`

本文是运行时工程契约，不是发布许可。它规定每类可玩状态的唯一写入者、读取者和更新顺序，避免候选模型、视觉表现层或截图采集器直接改变玩法结果。

## 状态归属

| 状态 | 唯一写入者 | 允许读取者 | 禁止行为 |
|---|---|---|---|
| 当前输入帧 | 场景的输入编排器 | 玩家、载具、暂停层、回放记录器 | 视觉脚本直接修改玩家或载具速度 |
| 玩家移动、蹲伏和动作状态 | `player_controller.gd` | 镜头、感知、任务、HUD、存档快照 | NPC、HUD 或资产包装器直接写入玩家变换 |
| 第三人称镜头轨道与遮挡修正 | `third_person_camera.gd` | 场景、截图采集器、存档 | 角色模型替换器改变镜头碰撞或轨道参数 |
| NPC 感知与警觉状态 | `perception_state.gd` 及 NPC 场景 | 任务、HUD、回放、存档 | 视觉材质或截图采集器改变警觉阶段 |
| 城市冲突、生命和闪避窗口 | `conflict_state.gd`；城市场景只编排输入与反馈 | 城市场景、HUD、音频、回放、存档 | HUD 或视觉层直接增减生命、跳过闪避冷却或击败对手 |
| 任务阶段与失败/重试 | `mission_state.gd`、`mission_chain.gd` | 场景、交互、HUD、存档 | UI 文本直接推进任务阶段 |
| 物品与库存 | `inventory_state.gd` | 交互、任务、HUD、存档 | 道具网格直接增加或删除物品 |
| 载具驾驶、耐久与挂点状态 | `vehicle_controller.gd` | 城市场景、任务、HUD、存档、回放 | 载具视觉候选改变碰撞、驾驶挂点或速度规则 |
| 暂停、输入锁定和音频开关 | `pause_overlay.gd` | 场景、HUD、设置存储 | 暂停层在锁定期间继续推进任务或感知 |
| 办公室/城市存档 | `save_store.gd` | 启动器、场景、恢复测试 | 运行时视觉脚本绕过存档版本与校验 |
| 异常退出标记 | `session_journal.gd` | 启动器、恢复测试 | 视觉采集器删除或伪造会话标记 |
| 确定性事件轨迹 | `trace_recorder.gd`、`replay_tape.gd` | 测试、证据生成器 | 人工视觉签收修改行为轨迹或输入记录 |

## 每帧更新顺序

1. 场景接收键鼠/手柄输入，生成一份不可变输入帧。
2. 暂停层先决定输入是否被消费；暂停时只允许菜单操作，不推进世界状态。
3. 回放记录器记录输入帧和必要的事件标记。
4. 玩家或载具控制器消费输入，更新移动、动作和碰撞结果。
5. NPC 感知读取新的玩家/载具位置，推进警觉状态和冲突事件；冲突状态机消费贴身威胁并处理生命损失或闪避无伤窗口。
6. 交互系统根据当前位置和目标挂点请求库存或任务变更。
7. 任务状态机处理已确认的事件，产生任务阶段、失败或完成结果。
8. 存档在明确的检查点写入快照；普通帧不隐式改写存档。
9. HUD 只读取本帧快照并呈现文字、符号、音频提示和反馈色。
10. 视觉候选层最后更新网格、材质和装饰表现，不得回写上述玩法状态。

## 场景边界

- 办公室场景负责潜行流程的编排、检查点和返回启动器，不拥有玩家、NPC、任务或存档的第二份副本。
- 城市场景负责街区入口、载具挂接、人群/交通编排和城市检查点，不改变通用任务、库存和存档数据结构。
- 启动器只负责入口选择、设置、会话恢复提示和场景切换；它不直接推进办公室或城市任务。
- 参考视频采集器只负责固定镜头、输入回放、截图和证据清单；采集结果默认 `unverified`，不能改变发布状态。

## 验证方式

当前契约由以下证据共同验证：

- `npm run test:reference:functional`：核心场景、任务、感知、载具、HUD、存档和确定性回放。
- `npm run test:expanded-behavior`：暂停、恢复、城市扩展、内容包和会话日志。
- `npm run test:rollback`：候选构建文件级回滚。
- `npm run verify:asset-delivery`：确保表现层没有静默替代灰盒契约。
- `npm run verify:visual-freshness`：确保过期或错源截图不会进入视觉验收。

任何新增系统必须先指定唯一写入者和更新阶段，再添加实现与回放测试；不能通过在 HUD、资产包装器或采集脚本中写入状态来绕过系统边界。
