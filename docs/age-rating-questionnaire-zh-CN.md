# 《新时代觉醒者》年龄分级问卷草案

状态：内部问卷草案，不是平台正式分级结果；最终角色、动画、音频和商店版本确定后必须重新填写。

适用范围：Steam Windows 首发办公室垂直切片，简体中文，免费测试版，不接真实支付。

## 当前可验证内容

| 项目 | 当前研发基线判断 | 最终确认要求 |
|---|---|---|
| 暴力 | 有轻度 NPC 冲突、追逐、生命值减少和失败反馈 | 用最终动画、音效和镜头重新判断是否出现血液、肢解或逼真伤害 |
| 恐怖 | 有被发现、警觉和追逐压力 | 检查最终灯光、音效和失败演出是否增加惊吓或恐怖表现 |
| 赌博 | 无抽奖、博彩或随机付费奖励 | 商店版本不得新增相关系统 |
| 真实支付 | 当前不接入 | 若增加付费必须重新申报并改写隐私与商业化材料 |
| 在线互动 | 无联机、聊天、用户生成内容或好友系统 | Steam 配置不得启用未审计的在线功能 |
| 现实品牌和商标 | 使用原创名称与虚构标识 | 最终门面、道具、字体和宣传图逐项复核 |
| 用户数据 | 当前仅本地存档、输入回放、事件时间轴和设置 | 若接入崩溃上传、云存档或分析必须重新评估 |

## 当前临时结论

当前灰盒基线暂按“轻度冲突、无血腥、无真实支付、无在线互动”准备内部测试材料。这个临时结论不等于 Steam 的正式年龄分级，也不能在最终资产和音频未验收前写入商店页面。
