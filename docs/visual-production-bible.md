# 《新时代觉醒者》视觉生产圣经

配套的可视化验收入口：[视觉生产画廊](/Users/superjj/gamehub-mini-games/art-preview/visual-concept-gallery.html)。清单变更后执行 `npm run visual:concept-gallery` 重新生成。

视觉清单门禁会强制检查办公室 10 段与城市 11 段是否全部被视觉生产稿覆盖；执行 `npm run verify:visual-concept-manifest` 时必须得到 `逻辑状态覆盖 21/21`。这只证明生产计划完整，不代表真实运行时视觉已经通过。

版本：`0.1.0-dev`  
用途：把参考视频中已经确认的玩法状态，转换为可以进入 Godot 运行时的角色、场景、载具、道具、镜头和界面视觉资产。

## 1. 目标与边界

目标不是做一张“像 GTA 的宣传图”，而是把可观察到的参考内容逐段还原为可操作的游戏画面：

- 玩家可以在办公室中移动、蹲伏、绕过工位、被 NPC 发现、失败、重试和到达出口。
- 玩家可以在城市中接近店铺、领取物品、触发冲突、登记三轮车、驾驶、受损并抵达终点。
- 每个视觉元素必须绑定到真实状态、真实碰撞、真实输入或真实反馈；只存在于图片、不参与运行时的元素不得进入“完成”状态。
- 参考视频只作为镜头、节奏、构图和可观察事实来源；发布资产必须是项目原创或已完成权利签收的资产。

## 2. 风格支柱

### 2.1 写实叙事比例

角色、工位和载具采用自然人体比例与真实接触关系。禁止漂浮的手、悬空的坐姿、穿透桌面、车辆座椅与驾驶员脱离等问题。

### 2.2 暖暗办公、金色城市

- 办公室：低饱和灰褐、冷灰隔断、暖白顶灯和窗边橙色反光。
- 城市：黄昏金色逆光、湿润路面、低对比远景、冷蓝三轮车作为主要识别色。
- HUD：黑色半透明底、浅灰正文、金色目标强调、绿色生命/体力反馈、红色失败与警觉反馈。

### 2.3 形状语言

- 玩家：窄肩、背包、连帽外套、工装裤和运动鞋，轮廓必须在肩后镜头中一眼可识别。
- NPC：西装、短发、硬朗肩线、手持平板或对讲设备，警觉状态通过姿势和红色状态灯表达。
- 三轮车：蓝色车体、开放货斗、低矮驾驶位、三只轮胎、透明挡风片和货箱固定带。
- 办公室：连续工位、隔断、显示器、键盘、椅子、文件盒、灯槽和电梯厅构成可读空间方向。
- 城市：两侧店铺连续立面、树、路灯、车道线、路缘、少量交通车和远景楼群构成速度感。

## 4. 角色资产规格

### 4.1 玩家

- 成年男性，偏瘦但有自然肩背比例；深灰连帽外套、浅色内层、黑色工装裤、运动鞋、深色通勤背包。
- 必须提供：站立、行走、快走、蹲伏、蹲伏移动、交互、打字、上车、驾驶、受击、失败、闪避。
- 必须提供骨骼挂点：双手、双腕、骨盆、头部、背包、驾驶座、脚底接触、视线起点。
- 近景重点：肩胛连续面、手臂与桌面关系、臀部与椅面接触、背包与身体遮挡。

### 4.2 办公室 NPC

- 深色西装、短发、硬朗肩线；待机时自然站立，警觉时身体前倾并抬头寻找。
- 必须提供：待机、巡视、转身、警觉、搜索、追踪、冲突、失败后停顿。
- 视觉状态必须由运行时状态机驱动，不能只换材质颜色。

### 4.3 城市人群

- 配送员、居民、摊主、冲突对象四类身份；同一骨骼可通过服装色、帽子、手持物和步态区分。
- 远景降低面部细节，近景保留衣服轮廓、鞋、肩线和手持物。

## 5. 场景资产规格

### 5.1 办公室

主视线高度约 1.6 米，空间用连续工位和玻璃隔断表达；近景必须有真实显示器、键盘、文件盒、台灯、椅子扶手和桌面前沿。所有可见物体分为碰撞层、交互层和纯表现层，避免用背景图卡替代可走空间。

### 5.2 城市

城市优先保障驾驶路线的可读性：道路边界、车道线、路缘和店铺入口优先于远景装饰。道路材质要支持黄昏、雨后和受损反馈；树、路灯和交通车要有近中远三档细节和裁剪距离。

## 6. 载具与道具规格

- 三轮车：蓝色车体、开放货斗、驾驶座、挡风片、方向盘/把手、货箱、三只轮胎、车灯、牌照、损伤刮痕和烟雾反馈。
- 鸡蛋托盘：领取前静态、领取后挂在玩家/货斗、冲突时可掉落或保持任务绑定，必须由任务状态控制。
- 登记牌：二维码/登记标识只作为原创图形，必须绑定登记交互区域和完成反馈。
- 办公室电梯：门体、门框、楼层牌、呼叫面板和目标光带必须独立可替换。

## 7. 镜头、灯光与材质规则

- 办公室默认肩后偏左；玩家蹲伏时镜头高度随身体降低，但不穿透桌面和隔断。
- 城市驾驶采用低机位后视追踪，玩家和车体占画面约 20%～30%，道路消失点保持在画面中线附近。
- 角色材质：皮肤粗糙度高于塑料，服装有细微法线和褶皱，背包不使用纯黑无层次材质。
- 办公室材质：桌面半哑光、玻璃低透明、金属边框有冷色反光、顶灯暖白。
- 城市材质：道路湿润但不镜面，车体有边缘高光，店铺玻璃和路灯有金色反射。
- 任何视觉稿必须同时给出正面、侧面、背面、近景接触关系和游戏镜头构图，不能只交一张海报。

## 8. 生产顺序

1. 玩家角色：站立/蹲伏/打字/驾驶四个关键姿态。
2. 办公室垂直切片：工位、隔断、电梯厅、NPC和 HUD。
3. 三轮车：后视驾驶构图、驾驶员接触、货斗和损伤反馈。
4. 城市驾驶路线：店铺、道路、树、路灯、交通车和终点门面。
5. 城市人群、鸡蛋托盘、登记牌和冲突表现。
6. 扩展天气、仓储后场、失败/暂停/重试和多分辨率 HUD。

## 9. 美术验收门槛

每个资产进入运行时前必须同时具备：

- 视觉稿：角色/物体设计、材质、颜色、比例和关键姿态。
- 运行时绑定：GLB/场景路径、挂点、碰撞代理、动画状态和逻辑事件。
- 状态证据：至少一条可重复输入回放和一张同源运行时截图。
- 人工对照：逐帧对照参考视频，检查轮廓、比例、材质、光照、镜头、动作、遮挡和 HUD。
- 发布条件：权利、性能、Windows 设备和 Steam 材料全部通过。

在上述条件全部满足前，资产只能标记为 `candidate` 或 `visual_unverified`，不能改成 `final`。
