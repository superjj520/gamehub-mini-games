```text
<区域>-<对象>-<变体>-<版本>.<格式>
```

例如：`office-player-original-v1.glb`、`city-three-wheel-delivery-v2.glb`。

## 4. 导出与材质要求

- 游戏运行时优先使用 `glTF/GLB`。
- 导出时应用变换、三角化、法线和切线；保留 UV，必要时保留顶点色。
- 角色需要明确骨架名称、脚底接触、面向方向和动画剪辑名。
- 材质必须在 Godot 实际窗口中检查；静态导入成功不等于光照、透明度和粗糙度正确。
- 透明材质必须记录排序、剔除和深度显示策略，避免隔断、玻璃和 HUD 互相冲白。
