## 第一轮视觉验收入口

图形环境恢复后，可从工作区根目录执行 `npm run playtest:candidate:office:full`，启动当前办公室 P0 组合候选。该入口在临时运行时副本中执行导入和回放，关闭 Godot 后自动清理；它只用于视觉方向审阅，不能替代逐帧签收。

第一轮只验收“方向和可读性”，不验收最终发布：

1. 主角肩后镜头：服装、背包、头发、手部和脚底轮廓是否可读。
2. 办公室出生镜头：角色比例、工位尺度、隔断遮挡和暖色灯光是否匹配目标方向。
3. NPC 近景镜头：上司与巡查 NPC 是否能通过服装和姿态区分。
4. 失败/重试镜头：角色动作、HUD 和镜头恢复是否仍然清楚。

上述验收通过后，才继续扩大 P0 资产生产；任何一项不通过都回到候选资产返工，不会把灰盒或静态预览直接推进发布。
