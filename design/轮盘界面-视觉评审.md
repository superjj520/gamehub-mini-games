# 轮盘界面 视觉与信息层级评审

> 评审对象：18+ 派对游戏「轮盘」射击回合界面
> 可交互对照稿：[`design/roulette-mock.html`](./roulette-mock.html) — 自带「改前/改后」切换与「实弹/空膛」试射
> 所有对比度按 WCAG 2.1 相对亮度公式实算，不是估的

---

## 一句话结论

**弹巢该是唯一主体，百分比是它的读数而不是并列的第二主体；金球从不缺对比度，缺的是形态；三个按钮现在是「颜色主次」不是「结构主次」；中弹反馈缺的是「让位」这一步。**

![改前](./shots/roulette-1-before.png)

上图是现状的合理还原。它不难看——但视线第一落点在 `33%`，不在枪上。

## 1. 弹巢 / 百分比 / 玩家列表，谁是视觉主体

### 排序

| 层级 | 元素 | 理由 |
|---|---|---|
| **L0 主体** | 弹巢 | 每一次决策（开不开枪、加不加弹）都要看它；它是唯一承载「会不会死」的空间信息 |
| **L1 读数** | 百分比 | 是弹巢的派生值，不是独立信息源 |
| **L2 状态带** | 玩家列表 | 一局里只变 1~2 次，属于长期状态，不该抢瞬时焦点 |
| **L3 辅助** | 顶部房号/轮次、角标、快捷键提示 | 只在需要时被找 |

### 为什么数字不能当主体

1. **信息增量是 0。** 盘上已经写着全部事实：6 个膛、2 颗实弹、粉环标着待击发位置。数字是把这三个已知量算成的一个商。把一个派生值做成 96px 独占一块视觉中心，等于让玩家读答案而不读题。
2. **两股力量互相削弱。** 现在弹巢和数字是两个都亮、都大、都不动的物体。视线必须在它们之间来回跳一次才能拼出「33% 是这颗盘的概率」。任何需要二次拼合的界面，第一眼都是失败的。
3. **数字的位置离决策最远。** 数字在盘下方，玩家的手在底部，眼睛要往下走。而真正要做判断的位置是「粉环那一膛现在对着谁」。

### 改法：把数字塞进盘心

盘心本来就有靶心语义，就是为这个留的。

![改后](./shots/roulette-2-after.png)

- 位移只有一个：数字从盘下的大字块，收进盘心。
- 视觉重量几乎没减（66px vs 96px），但因为**它在对象内部**，弹巢和数字合并成同一个焦点。
- 盘径同时从 258 → 352，把省下来的纵向空间还给主体。
- 盘心的暗底让渐变数字反而更亮，读数更清楚。

### 玩家列表怎么处理才不抢戏

- 加一行 `在场玩家 · 3 / 4` 的微型标题，把它从「飘着的卡片」变成有归属的一段。
- 当前回合的卡只用**一条左侧竖条 + 1.5px 紫边**标记，不要整块发光——发光是留给开枪的。
- 卡片高度 58px、圆角 14px：高于 44px 触控底线，低于「可点」的暗示（它不是按钮）。

## 2. 金色球体在深紫背景下是否足够可辨

**结论：够，而且过亮。** 这是全屏对比度最高的元素之一。

| 组合 | 对比度 | 判定 |
|---|---|---|
| 现行金球 `#F0B429` / 深紫底 `#1A0B2E` | **9.96:1** | ✅ 远超 AA（4.5:1），甚至超过 AAA 的 7:1 |
| 建议金球 `#FFD24A` / 深紫底 `#1A0B2E` | **12.88:1** | ✅ |
| 建议金球 `#FFD24A` / 盘面 `#241335` | **11.95:1** | ✅ |
| 金球描边 `#5C3A0A` / 金球 `#FFD24A` | **7.06:1** | ✅ |

### 那为什么看着还是「不够醒目」

三个真问题，没有一个是亮度：

1. **尺寸与均质。** 258 盘上球径 37px，只占盘径 14.4%。更关键的是 6 个膛在结构上完全均质，实弹只靠「更亮」来区分——快速扫视时大脑靠的是**形状和位置**，不是亮度差。
2. **高光过曝。** 现在高光是一大块近白，球读起来像「发光的糖」而不是「抛光的黄铜」。镜面高光应该只占球径 22% 以内，且必须紧贴光源方向。
3. **没有描边，也没有落地阴影。** 金球和粉光环、紫盘之间没有任何分隔，光晕会互相污染——尤其是当前膛的粉环和金球相邻时，两者会糊在一起。

### 修法（具体到值）

```css
/* 球体：高光收紧 + 底部内阴影 + 描边 + 落地投影 */
.ball{
  inset:13%;                                  /* 球 = 膛室 74% */
  background:radial-gradient(circle at 34% 26%,
    #FFFDF2 0%, #FFF3C4 6%, #FFD24A 30%,
    #F0B429 54%, #C98A12 76%, #7A4A08 100%);
  box-shadow:
    0 0 0 1.5px #5C3A0A,                      /* 描边，与金球 7.06:1 */
    inset 0 -8px 12px -6px rgba(60,32,0,.95), /* 底缘内阴影：造出球面的暗部 */
    0 5px 10px -2px rgba(0,0,0,.85),          /* 落地投影：球在膛里，不在膛上 */
    0 0 11px rgba(255,210,74,.22);            /* 外发光只留一点点，别让它变灯 */
}
```

> 高光 `#FFF3C6` 对金球 `#FFD24A` 只有 **1.30:1** —— 这不是错误，镜面高光本来就该是极小面积的高反差点。**但如果把这块白放大，球就死了。**

### 真正的对比度问题在别处

| 组合 | 对比度 | 判定 |
|---|---|---|
| 空膛底 `#0C0616` / 盘面 `#241335` | **1.16:1** | ❌ 空膛几乎读不出来 |
| 膛口描边 `#6B4E8F` / 盘面 | **2.55:1** | ❌ 低于非文本 3:1 门槛 |
| 加强后描边 `#8A6BAE` / 盘面 | **3.93:1** | ✅ 勉强过线 |
| 已击发膛口 `#7A6B8C` / 盘面 | **3.53:1** | ⚠️ 只在纯色时成立，实做要加虚线圈 |

**空膛不是「没有东西」，它是「有东西但是空的」——这个「空的」必须看得见。** 通过 1px 亮边把膛口轮廓勾出来，比调亮膛底更重要。

### 色盲冗余（这条不能省）

金色在红色盲视角下会退成土黄，粉色和紫色几乎不可分。所以三种膛态必须**形状不同**，不能只靠颜色：

| 膛态 | 形状语言 |
|---|---|
| 实弹 | 球体（有高光、有投影的圆） |
| 空膛 | 硬边圆洞（纯黑，只有 1px 亮边） |
| 已击发 | 虚线熄火圈 + 内部焦痕 |
| 当前膛 | 外加一圈光环 |

## 3. 三个底部按钮的主次

### 现在的问题

改前：三个按钮 **同高 52px、同宽三等分、同圆角**，唯一区别是开枪是红的。

这不是主次，这是**「三名员工穿不同颜色的工牌」**。用户读到的是「三个都差不多，其中一个是红的」，而不是「这里只有一个真正的决定」。

⚠️ 更糟的是：红色按钮是这屏第二亮的东西，于是**最危险的动作变成了最吸引点击的元素**。危险 ≠ 该被点。

### 改后

| 层级 | 按钮 | 尺寸 | 视觉 | 交互 |
|---|---|---|---|---|
| 次级 | 转弹仓 | 48px 高 · 内容定宽 | ghost：`rgba(255,255,255,.045)` + `1px` 紫边 + `#D9CBEF` 文字 | 单击即生效（可逆，能再转） |
| 次级 | 加一颗 | 48px 高 · 内容定宽 | 同上 | 单击即生效（可撤销） |
| **主危险** | 开枪 | **64px 高 · 撑满剩余** | 唯一饱和红渐变 + 顶部内高光 + 底部投影 + 红晕 | **长按 0.6s 充能** |

```css
/* 主危险行动：唯一饱和色 + 唯一大尺寸 + 唯一强投影 */
.btn--fire{
  flex:1 1 auto; height:64px; font-size:17px; font-weight:750; letter-spacing:.14em;
  background:linear-gradient(180deg,#FF3A5B 0%,#C9103A 55%,#9E0A2C 100%);
  box-shadow:
    inset 0 1px 0 rgba(255,255,255,.32),
    inset 0 -2px 0 rgba(0,0,0,.35),
    0 10px 28px -10px rgba(255,34,68,.85),
    0 0 0 1px rgba(255,92,120,.35);
}
/* 次级：形状弱、颜色弱、尺寸弱，但触控面积仍 ≥ 44px */
.btn--ghost{ flex:0 0 auto; height:48px; padding:0 13px; font-size:13px; color:#D9CBEF }
```

### 危险动作到底怎么表达

四层叠加，缺一层就会被误触：

1. **尺寸与位置** — 最大、最右（右手拇指自然落点），但**不许**占满整个宽度（否则会变成「默认继续」）。
2. **颜色** — 全屏唯一饱和红 `#FF2244` 系。红色只此一处，别无分号。
3. **摩擦** — 长按 0.6 秒，环形成功才击发。**这不是动效装饰，这是防误触的物理成本。** 松手即取消，进度归零。
4. **语义文案** — 别写「开枪」，写「对 阿岚 开枪」。把对象写进按钮，让误触在按下那一刻就不成立。

> 反模式警示：红色 + 大尺寸 + 一键即发 = 把最不可逆的动作做成了最容易点到的目标。三者必须至少拆掉一个。

### 快捷键

`R` 之类的小徽标只在 `@media (hover:none)` 以外显示：

```css
@media (hover:none){ .kbd{display:none} }
```

在触屏设备上印键盘提示，不是细节，是噪音。

## 4. 中弹瞬间的反馈

### 原则：结果必须**接管**画面，不是**叠加**在画面上

改前的问题不是「没反馈」，是反馈**和原来那一屏抢位置**——「砰」会压在百分比上，两个都读不清。

改后的关键动作是**让位**：命中瞬间，盘心的数字降到 4% 亮度退场，把靶心交给结果。

![中弹瞬间](./shots/roulette-3-hit.png)

### 时间轴

| 时刻 | 事件 | 参数 |
|---|---|---|
| t=0 | 按下开枪 | 充能环起，盘面亮度 +8%（紧张感预抬） |
| 0→600ms | 长按充能 | 环形进度 0→100%，期间松手即取消 |
| 600ms | **击发** | 白闪 `#FFF3F6` 0.16s，峰值 85% 后立即归零 |
| 600ms | 画面抖动 | 0.42s，位移 8px 递减到 0（`prefers-reduced-motion` 下禁用） |
| 600ms | 数字让位 | 盘心 `opacity: .04`，0.18s |
| 720ms | 冲击环 | 0.5s，scale 0.6→2.3，边框 12px→1px 收细，粉 `#FF2E9A`，60% 时开始淡出 |
| 720ms | 「砰」登场 | 0.95s：scale .42→1.14→1.0，同时 `blur 8px→0`，末段上移淡出 |
| 740ms | 受害者结算 | 血心 3→2：先 scale 1.45 再崩解；头像 `grayscale(1) brightness(.5)`；名字加红色删除线；卡片 1.5px 红边 + 左侧红晕 |
| 700ms | **全场压暗** | 玩家列表 + 按钮 `filter: brightness(.5) saturate(.75)`，0.3s 延迟 0.1s —— 视线被强制拉回盘面 |
| 1300ms | 恢复交互 | 压暗解除，进入下一回合 |

### 三条硬约束

1. **同时最多两个动态**（抖动 + 大字）。其余全部用明暗变化。三个以上同时动 = 什么都看不清。
2. **结果要落在「发生地」。**「砰」在盘心，血心在卡片，各自在各自的坐标上，不要飞到屏幕中央。
3. **不写「-1 点血」。** 心形崩解本身就是结算，加数字是画蛇添足。

### 空膛不能只是「没事发生」

空膛是最容易被做坏的状态。它必须给一个**正向**的推进感：

![空膛](./shots/roulette-4-empty.png)

- 干「咔」+ 盘面 0.32s 的 `scale(.995)` 回弹（几乎看不见，但身体能感觉到）
- 当前膛的粉环**必须移交给下一膛**，老膛变成虚线熄火圈
- 移交动画 180ms：让玩家确认「我往前推进了一格，而且刚才那颗是空的」

> 如果粉环直接消失，玩家会立刻失去「我打到第几枪」的空间记忆——这是轮盘赌最核心的心智模型，不能断。

## 5. 落地规格

### 5.1 尺寸表（全部由 `--disc` 派生）

改尺寸只需要改一个变量，膛室/球/盘心会等比跟着走。

| 元素 | 258 版（改前） | 352 版（改后） | 公式 |
|---|---|---|---|
| 盘径 | 258 | 352 | `--disc` |
| 膛室直径 | 50 | 68 | `calc(var(--disc) * .194)` |
| 实弹直径 | 37 | 51 | 膛室的 74%（`inset:13%`） |
| 膛心轨半径 | 84 | 114 | `calc(var(--disc) * .325)` |
| 盘心直径 | — | 141 | `calc(var(--disc) * .40)` |
| 盘心数字字号 | — | 62 | `calc(var(--disc) * .175)` |
| 盘下大字 | 96 | — | 已移除 |
| 玩家卡片高 | 58 | 58 | 固定 |
| 主按钮高 | 52 | **64** | 固定 |
| 次按钮高 | 52 | 48 | 固定 |

```css
.disc{ width:var(--disc); height:var(--disc) }
.well{
  width:calc(var(--disc) * .194); height:calc(var(--disc) * .194);
  /* 6 等分：--a 由 JS 注入 0/60/120/180/240/300deg */
  transform:translate(-50%,-50%) rotate(var(--a,0deg)) translateY(calc(var(--disc) * -.325));
}
```

### 5.2 颜色令牌

直接并进 [`design-system.css`](../design-system.css)，与既有 `--brand / --gold / --surface-*` 同层。

```css
:root{
  /* —— 底与面 —— */
  --rl-bg-deep:   #0B0614;   /* 页面底 */
  --rl-bg-mid:    #1A0B2E;   /* 深紫，金球对比基准 */
  --rl-disc-base: #241335;   /* 盘面 */
  --rl-disc-edge: rgba(138,107,174,.30);
  --rl-well:      #0C0616;   /* 膛底，别更浅 */
  --rl-well-rim:  rgba(138,107,174,.55);  /* 膛口亮边，盘面 3.93:1 */

  /* —— 实弹 —— */
  --rl-gold:      #FFD24A;   /* 12.88:1 @ 深紫 */
  --rl-gold-hi:   #FFF3C6;
  --rl-gold-lo:   #7A4A08;
  --rl-gold-rim:  #5C3A0A;   /* 7.06:1 @ 金球 */

  /* —— 品牌霓虹 —— */
  --rl-pink:      #FF2E9A;   /* 5.40:1 @ 深紫，当前膛+/冲击环 */
  --rl-violet:    #A855F7;
  --rl-num-top:   #FF8BC1;   /* 7.22:1 */
  --rl-num-bot:   #B36BFF;   /* 5.71:1 */

  /* —— 危险 —— */
  --rl-danger:    #FF2244;   /* 5.30:1 @ 页面底 */
  --rl-danger-d:  #C9103A;
  --rl-blood:     #FF1E3C;   /* 4.79:1 @ 卡片底 */

  /* —— 文字 —— */
  --rl-text:      #F4EEFF;   /* 16.37:1 */
  --rl-text-2:    #B9A4D6;   /* 8.26:1 */
  --rl-text-3:    #7E6C97;   /* 仅用于 ≥10px 的辅助标签 */

  /* —— 卡面 —— */
  --rl-card:      #1C0E2C;
  --rl-line:      rgba(167,139,250,.16);
}
```

**用法红线**

- `--rl-text-3` 只能出现在 `letter-spacing ≥ .14em` 的全大写/等宽微型标签上，且字号 ≥10.5px。
- 粉色 `--rl-pink` 全屏**最多两处**：当前膛光环 + 冲击环。多一处就散。
- `--rl-danger` 全屏**仅一处**：开枪按钮。别用它标血量、别用它标 18+。

### 5.3 层级顺序（z-index 与注意力顺序是两件事）

```
z 9   .fx            风暴层（闪光 / 冲击环）       pointer-events:none
z 8   .hint          临时提示
z 5   .boom          「砰」，长在盘心上
z 3   .hub / .pin    盘心读数（L1）
z 2   .well          6 个膛室 + 球（L0）
z 1   .groove        6 条机加工凹槽
z 0   盘体渐变 / 扫描线
```

**注意力顺序（与 z-index 无关，由明度决定）**：
`弹巢(最亮) → 开枪按钮(唯一饱和) → 当前膛光环 → 玩家列表当前行 → 其余`

改动前违反这条的地方：盘下 96px 数字的明度和面积都压过了弹巢，注意力顺序变成了 `数字 → 弹巢 → …`。

### 5.4 状态矩阵（先定状态，再定样式）

| 状态 | 盘心 | 当前膛 | 玩家列表 | 开枪按钮 |
|---|---|---|---|---|
| 待发（我的回合） | `100%`，粉紫 | 粉环静态呼吸 2.6s | 一行高亮 | 可用，长按充能 |
| 充能中 | `100%` + 亮度 +8% | 粉环加速到 0.8s | 不变 | 环形成长，`scale(.985)` |
| 中弹 | **`.04`** | 粉环碎裂 | 受害行红边 + 血心 -1，其余压暗至 50% | 禁用 0.7s |
| 空膛 | `100%` 短暂 +6% | 变虚线熄火，**光环移交下一膛** | 不变 | 禁用 0.46s |
| 出局 | — | — | 整行 `opacity:.45` + 「出局」标签，头像灰 | — |
| 别人的回合 | `100%`，降饱和 20% | 粉环静止 | 高亮权移交 | **禁用 + 文案「等 阿岚 决定」** |
| 只剩 1 膛 1 实弹 | `100%`，加红描边 | 粉环 + 红边 | — | 文案「对 阿岚 开枪 · 必中」 |

> 「别人的回合」这一态现在完全没有。它最容易做错：按钮直接 `disabled` 会让人以为是卡了。禁用态必须**用文案解释为什么**。

### 5.5 动效预算

```css
/* 所有动画统一走三条曲线，别再多 */
--ease-pop: cubic-bezier(.2,1.5,.4,1);      /* 弹入，会过冲 */
--ease-out: cubic-bezier(.16,1,.3,1);       /* 位移与缩放，不过冲 */
--ease-io:  cubic-bezier(.4,0,.2,1);        /* 明暗过渡 */

@media (prefers-reduced-motion: reduce){
  *{ animation-duration:.001ms !important; transition-duration:.001ms !important }
  /* 抖动、冲击环、砰的模糊全部退化；血量与文案变化必须保留 */
}
```

⚠️ 一个实测坑：`--ease-pop` 会过冲，**不能用在「1 → 0」的淡出段上**——过冲会把 opacity 提前压到 0，动画看起来像被吞掉了。「砰」的淡出必须换 `--ease-out`。

### 5.6 盘面质感（让「这是转轮」0.3 秒读出来）

两个细节决定了它像不像金属，成本都很低：

1. **6 条机加工凹槽**，落在两个膛之间（30°/90°/150°…），定宽、等长、止于轮缘内侧。
   ⚠️ **不要用 `repeating-conic-gradient` 画**——它会把凹槽画成外宽内窄的黑色裂缝，看起来像盘裂了。用定宽元素 + `rotate()` 平移到半径上。
2. **盘心轴盖**（改前没有盘心读数时必要）：`conic-gradient` 在圆心会露出接缝，形成一道「X」形暗痕。一枚 21% 盘径的棘轮盖正好遮掉，而且更真实。

## 6. 这次没覆盖的

- **4 人以上**：列表会挤爆。需要「当前 + 下一位 + 折叠的其余玩家」，而不是无限滚。
- **音效设计**：砰/咔/心跳三层，尤其是长按那 0.6 秒必须有渐强——现在完全靠视觉撑紧张感，撑不住。
- **真实数据联动**：对照稿里「剩 6 发 · 实弹 2 颗」是静态的。命中后应变为 `剩 5 发 · 实弹 1 颗`，且盘上实弹数必须同步减。
- **18+ 内容的边界**：只做了「红」这一层，没有做血液/碎屏等更强刺激的档位。如果要留升级空间，应该在 `--rl-blood` 之外再加一个可开关的强度令牌，而不是把刺激直接焊死在基础样式里。
