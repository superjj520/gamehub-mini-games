# 主角三维候选导入失败记录

该目录保存 2026-10-13 的隔离导入实验，不属于正式运行时，也不属于发布候选。

- 参考来源：已登记的 MakeHuman/MPFB2 角色图集候选，许可证记录在 `art-source/characters/makehuman-office-worker/MPFB-LICENSE.ASSETS.md`。
- 目标：验证写实人体候选能否通过原有 `Visual` 接口接入，并保留任务、碰撞、镜头和姿态状态契约。
- 结果：原始图集候选在图形导入阶段触发 Zstandard/着色器转换相关的引擎崩溃，后台 Blender 重新导出同样发生进程级崩溃。随后将无纹理清洗版做成兼容候选：编辑器导入可以完成、8 个网格和 5/5 状态接口的无窗口契约通过，但在实际场景实例化时仍触发同一渲染后端崩溃。进一步测试无蒙皮静态西装版：编辑器导入、7 个网格和 5/5 状态接口通过，但进入真实办公室渲染场景仍触发同一崩溃，因此也不能视为可用。
- 处置：原始版和清洗兼容版均已移回本目录，未把候选接入 `gta-reference-runtime/assets/` 的正式角色场景；正式源码、视觉矩阵和发布清单保持原有 `ee40… / 231` 绑定。

重新尝试前必须先在隔离工程中完成：无窗口导入、可见窗口导入、材质读取、骨骼姿态、Windows 目标设备和资产哈希复核；任一项失败都不能回接正式运行时。
