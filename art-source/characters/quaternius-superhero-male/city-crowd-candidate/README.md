# 城市人群候选包

这是城市人群视觉候选包，不属于正式运行时或发布包。

候选包复用已经登记的 `character_npc_outfitted.glb`，由本项目代码提供确定性服装配色、`idle_default`、`walk_default`、`displaced_default`、`hit_default` 四个候选状态，以及真实 `Skeleton3D` 姿态驱动。它只承担视觉和姿态，不承担碰撞、路线或任务逻辑。

## 当前状态

- 固定镜头视觉、近景材质、人群密度、LOD、目标设备性能和最终资产签收仍未完成。

## 重新接入方式

把本目录中的脚本、场景、覆盖目录和测试复制到 `gta-reference-runtime` 的对应位置，再运行 `city_crowd_candidate_test.gd`。接入后必须重新采集扩展视觉矩阵，不能沿用旧截图的源指纹。
